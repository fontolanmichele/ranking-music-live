# Music Ranking Live — GitHub Edition

Questa è la versione **vuota** di Music Ranking Live: non contiene ascolti precaricati.

## Funzioni
- Ranking, Blind Ranking e Tier List.
- Caricamento PDF con estrazione dei link cliccabili.
- Aggiunta manuale degli ascolti.
- Immagini: nessuna, caricamento dal PC/tablet, URL, miniatura YouTube.
- Accesso studenti via QR con solo stanza + nickname.
- Nomi dei partecipanti visibili al docente.
- Risultati personali e di classe con switch finale.
- Interfaccia musicale colorata.

## Architettura
- GitHub Pages: interfaccia.
- Firebase Authentication anonima: accesso tecnico senza login visibile.
- Firebase Realtime Database: stanza, voti e risultati in tempo reale.
